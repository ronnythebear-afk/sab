# Add things here

- **photos**: old photos for the old hard drive. Name a file what you want it to say ("my tiny christmas tree.jpg") or leave the camera's name for no caption.
- **selfies**: selfies for the photo booth strips. Ones where your face is clear and fills a good part of the frame work best.

On GitHub: open the folder, then Add file, then Upload files, drag them in, and Commit changes. A couple of minutes later they're on the site and gone from here. A selfie that stays means the booth couldn't find a face in it.
